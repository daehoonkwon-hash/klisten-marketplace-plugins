# ToolGuard — cursor client candidate

This local candidate adopts the existing ToolGuard Cursor static public OAuth configuration in root `mcp.json`, using the previously registered client and its exact existing three scopes. No new identity, callback, permission, key or consent was created. The2026-10-22 read-only metadata projection confirms the existing public/none provider is active and its legacy binding enabled; both Cursor web and localhost8787 callbacks are already registered.
